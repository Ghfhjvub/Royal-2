تطبيق إدارة ROYAL TABLE (صفحة المدير فقط)

1) ارفع محتويات هذا المجلد كما هي (index.html و sw.js و manifest.webmanifest ومجلد icons) إلى رابط HTTPS خاص بها، مثل مجلد أو مستودع منفصل على GitHub Pages.
2) افتح الرابط على جهاز المدير في Chrome ثم اضغط زر "تثبيت الإدارة" (أو القائمة ⋮ ثم "تثبيت التطبيق"). على الآيفون: Safari ثم مشاركة ثم "إضافة إلى الشاشة الرئيسية".
3) سيفتح التطبيق على شاشة دخول المدير مباشرة، دون أي رابط لصفحات المنيو أو الكاشير، والدخول يقبل حساب المدير فقط.
